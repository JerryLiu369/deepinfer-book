## 最重要的三句话

1. **子代理只交"事实笔记"，不写书。书里的每一句话都由主代理重新写。** 不要把子代理的段落复制进书稿。
2. **全书有一条主线**（见 `01_OUTLINE.md` 第 1 节）。每一章、每一节都要能说出自己在主线上的位置；说不出就删或改。
3. **每个事实都要有出处和证据等级**（见 `00_MASTER_SPEC.md` 第 6 节）。宁可写"文档没有说明"，也不要编。

## 开工前的第一个动作

读完全部文件后，先在 `work/plan.md` 里用自己的话写下：

1. 全书核心论点（一段话）。
2. 你打算怎么分三波派发子代理，每波派哪些任务。
3. 你认为最难写好的三章是哪三章，打算怎么应对。

写完再开始 P0。这一步是为了确认你真正理解了任务，而不是照着清单机械执行。
